ملفات تجربة Tabuk AR
====================

الملفات:
- index.html : صفحة AR الجاهزة.
- target.jpg : صورة الـTarget التي أرسلتِها.
- video.mp4 : ضعي هنا الفيديو الواحد الذي تريدين ظهوره فوق الصورة.
- targets.mind : ملف لازم يتولد من صورة target.jpg باستخدام MindAR Target Compiler.

الخطوات:
1) افتحي أداة MindAR Target Compiler.
2) ارفعي target.jpg.
3) حمّلي الملف targets.mind.
4) ضعي targets.mind داخل نفس المجلد مع index.html وvideo.mp4.
5) ارفعي الملفات الأربعة إلى GitHub.
6) فعّلي GitHub Pages من Settings > Pages > Deploy from branch > main > /(root).
7) افتحي رابط GitHub Pages على الجوال واسمحي بالكاميرا.

مهم: الفيديو يجب أن يكون باسم video.mp4.
